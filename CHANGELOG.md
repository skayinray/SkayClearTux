# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.0] — 2026-11-16

Большое кроссплатформенное обновление: теперь это приложение только для ПК —
**Linux, macOS и Windows** — с единым кодом и честной работой системных
разделов на каждой ОС.

### Добавлено
- **Кроссплатформенное ядро** `skaycleartux/backends/`: базовый интерфейс и
  отдельные реализации `LinuxBackend`, `MacOSBackend`, `WindowsBackend`.
  Выбор платформы — автоматический, недоступные функции не роняют программу.
- **macOS**: Homebrew (поиск/установка/обновления), `launchctl`, `diskutil`,
  `system_profiler`, `pmset` (батарея), `log show`, `lsof` (порты), корзина `~/.Trash`.
- **Windows**: `winget`/`choco`, службы Windows, `ipconfig`/`netstat`, WMI
  (железо, температура, батарея), `schtasks`, Журнал событий, очистка корзины.
- **Палитра команд** по `Ctrl+K` (и `Ctrl+F`): быстрый переход к любому разделу
  и запуск действий по поиску.
- **Системный трей**: значок с меню, быстрые переходы, сворачивание в трей при
  закрытии окна (по желанию) и одноразовая подсказка.
- **Горячие клавиши**: `F1` — справка, `Ctrl+R` — обновить страницу,
  `Ctrl+H` — главная, `Ctrl+Tab` — следующий раздел, `Ctrl+,` — настройки,
  `Ctrl+Q` — выход.
- **Дашборд**: метрики «Температура ЦП» и «Батарея».
- **Настройки**: разделы трея и горячих клавиш.

### Изменено
- Версия поднята до **1.2.0**; логотип и брендинг — Tux.
- `system_tools.py` стал тонким фасадом над бэкендами (имена API сохранены).
- `cleaner.py` переписан: категории мусора зависят от ОС (Linux — pacman/systemd,
  macOS — Homebrew/кэши, Windows — `%TEMP%`/кэши браузеров).
- Все подписи и справка приведены к кроссплатформенным формулировкам.
- Скрипты сборки и CI переехали в стандартные места
  (`.github/workflows/`, `packaging/`).

### Исправлено
- Убран личный жёстко прописанный путь корзины (`/mnt/.../.Trash-1000`).
- Убраны иконки-эмодзи из списка категорий очистки.
- Освобождение места на диске считается кроссплатформенно (`shutil.disk_usage`).
- Устранены символы, которые Qt рисовал пустыми квадратами.

### Удалено
- Мобильные порты (Android APK, iOS/TestFlight, PWA-клиент) — проект теперь
  только для ПК.

## [1.1.0] — 2026-11-15

Первая публичная версия для Linux (Arch и совместимые дистрибутивы):
34 экрана, 7 тем, очистка системы, монитор ресурсов, инструменты, шахматы с
ботом и рейтингом Эло, активность в Discord и дистанционные обновления.
