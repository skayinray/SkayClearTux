# SkayClearTux 1.5.2 — исправление вылетов и лагов в шахматах

Багфикс-релиз: устранены вылеты шахмат (в том числе при поражении/завершении партии и при проблемных состояниях), снижены лаги на высоких сложностях и повышена стабильность анализа ходов.

---

## Исправлено

### Шахматы
- **Устранены вылеты:** добавлена защита от повреждённых/некорректных состояний позиции (безопасная обработка отсутствия короля, проверок и статуса партии), чтобы движок и интерфейс не падали.
- **Стабильность интерфейса доски:** отрисовка, анимации, подсказки и значки ходов защищены от ошибок (включая отсутствие/некорректные ассеты фигур), что предотвращает падения во время партии.
- **Потоки бота и анализа:** улучшено управление фоновыми задачами (учёт актуальной партии, безопасная обработка завершения/сигналов, очистка устаревших задач), чтобы исключить вылеты при завершении партии, новой игре и отмене ходов.

### Производительность
- **Меньше лагов на высоких сложностях:** ограничены глубина/время поиска бота и подсказок, сокращён бюджет фонового анализа, очередь анализа очищается в пользу последнего хода — интерфейс остаётся отзывчивым.
- **Мелкие исправления:** корректный выбор превращения пешки в диалоге и более надёжное обновление статуса/рейтинга при завершении партии.

## Установка

| Платформа | Файл | Запуск |
|-----------|------|--------|
| Linux (любой) | `SkayClearTux-1.5.2-x86_64.AppImage` | `chmod +x` и запустить |
| Debian/Ubuntu | `SkayClearTux-1.5.2-amd64.deb` | `sudo apt install ./SkayClearTux-1.5.2-amd64.deb` |
| Fedora/RHEL/openSUSE | `SkayClearTux-1.5.2-x86_64.rpm` | `sudo dnf install ./SkayClearTux-1.5.2-x86_64.rpm` |
| Windows | `SkayClearTux-windows.zip` | распаковать, запустить `SkayClearTux.exe` |
| macOS | `SkayClearTux.dmg` | открыть образ, перетащить в «Программы» |

> **macOS (первый запуск).** Приложение не подписано — щёлкните правой кнопкой →
> **Открыть** → **Открыть**.

Из исходников:

```bash
git clone https://github.com/skayinray/SkayClearTux.git
cd SkayClearTux
python -m venv .venv
.venv/bin/pip install PySide6
.venv/bin/python SkayClearTux.py
```
