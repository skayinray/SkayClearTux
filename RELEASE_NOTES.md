# SkayClearTux 1.5.0 — исправления, оптимизация памяти и анализ шахмат

Обновление с исправлением проверки обновлений по SSL, более плавным и аккуратным
интерфейсом, новой оптимизацией памяти на главной и асинхронным анализом ходов в шахматах.

---

## Что нового

### Оптимизация памяти
- На главной странице появилась кнопка **«Оптимизировать память»**.
- Показываются подробные сведения об ОЗУ, подкачке и кэше.
- Выполняется безопасная оптимизация в один клик с учётом возможностей платформы
  (при необходимости запрашиваются права администратора).

### Анализ ходов в шахматах
- В списке ходов отображается оценка качества: **«Блестящий ход»**, **«Лучший ход»**,
  **«Отличный ход»**, **«Хороший ход»**, **«Неточность»**, **«Ошибка»**, **«Зевок»**.
- Анализ выполняется **асинхронно в фоне**, поэтому не усиливает лаги во время партии.

## Исправления

- **Обновления:** исправлена ошибка проверки
  `SSL: CERTIFICATE_VERIFY_FAILED (unable to get local issuer certificate)` в
  окружениях без корректных системных сертификатов (например, в некоторых
  AppImage/сборках). Для GitHub используется перебор доверенных SSL-контекстов.
- **Интерфейс:** исправлены обрезания текста на главной странице (герой-блок,
  карточки метрик, подсказки, быстрые действия).
- **Производительность:** снижены лаги главной страницы — метрики обновляются в
  фоне, а расчёт «здоровья системы» больше не выполняет повторный сбор тех же данных.

## Установка

| Платформа | Файл | Запуск |
|-----------|------|--------|
| Linux (любой) | `SkayClearTux-1.5.0-x86_64.AppImage` | `chmod +x` и запустить |
| Debian/Ubuntu | `SkayClearTux-1.5.0-amd64.deb` | `sudo apt install ./SkayClearTux-1.5.0-amd64.deb` |
| Fedora/RHEL/openSUSE | `SkayClearTux-1.5.0-x86_64.rpm` | `sudo dnf install ./SkayClearTux-1.5.0-x86_64.rpm` |
| Windows | `SkayClearTux-windows.zip` | распаковать, запустить `SkayClearTux.exe` |
| macOS | `SkayClearTux.dmg` | открыть образ, перетащить в «Программы» |

> **macOS (первый запуск).** Приложение не подписано — щёлкните правой кнопкой →
> **Открыть** → **Открыть**.

Из исходников:

```bash
git clone https://github.com/skayinray/SkayClearTux.git
cd SkayClearTux
python -m venv .venv
.venv/bin/pip install PySide6
.venv/bin/python SkayClearTux.py
```
