# SkayClearTux 1.5.3.1.1 — хотфикс зависания шахмат после хода

Срочный багфикс-релиз: устранено зависание/«замирание» шахмат после первого хода (когда программа продолжала работать, но шахматный экран переставал отвечать).

> Включает исправления из 1.5.3.1/1.5.2; релиз 1.5.3.1 на GitHub не был опубликован из-за конфликта тега, поэтому актуальная сборка — **1.5.3.1.1**.

---

## Исправлено
- **Зависание шахмат после хода:** исправлена обработка завершения фоновых потоков бота и анализа (защита от обращения к уже удалённым объектам потоков, корректная очистка ссылок и безопасное восстановление состояния интерфейса). Это устраняет ситуацию, когда после хода бот/анализ завершались, но шахматный экран переставал реагировать на действия.
- **Устойчивость ходов и анализа:** более надёжное применение результата хода бота и запуск/завершение фонового анализа, чтобы интерфейс оставался отзывчивым в течение партии.

## Установка

| Платформа | Файл | Запуск |
|-----------|------|--------|
| Linux (любой) | `SkayClearTux-1.5.3.1.1-x86_64.AppImage` | `chmod +x` и запустить |
| Debian/Ubuntu | `SkayClearTux-1.5.3.1.1-amd64.deb` | `sudo apt install ./SkayClearTux-1.5.3.1.1-amd64.deb` |
| Fedora/RHEL/openSUSE | `SkayClearTux-1.5.3.1.1-x86_64.rpm` | `sudo dnf install ./SkayClearTux-1.5.3.1.1-x86_64.rpm` |
| Windows | `SkayClearTux-windows.zip` | распаковать, запустить `SkayClearTux.exe` |
| macOS | `SkayClearTux.dmg` | открыть образ, перетащить в «Программы» |

> **macOS (первый запуск).** Приложение не подписано — щёлкните правой кнопкой →
> **Открыть** → **Открыть**.

Из исходников:

```bash
git clone https://github.com/skayinray/SkayClearTux.git
cd SkayClearTux
python -m venv .venv
.venv/bin/pip install PySide6
.venv/bin/python SkayClearTux.py
```
