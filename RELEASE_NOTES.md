# SkayClearTux 1.4.0 — крупное обновление

Финальный крупный релиз: Discord Rich Presence из коробки, исправления и новые
возможности шахмат, обновлённый интерфейс и новые инструменты.

---

## Что нового

### Discord Rich Presence из коробки
- В приложение встроен Discord Application ID `1571917686869331969`.
- Активность «В SkayClearTux» может отображаться без ручного ввода ключа
  (достаточно запущенного Discord). При необходимости ID по-прежнему можно задать
  в настройках или через `SKAYCLEARTUX_DISCORD_CLIENT_ID` / `DISCORD_CLIENT_ID`.

### Шахматы: стабильнее, быстрее, удобнее
- **Исправлен вылет при поражении** и повышена устойчивость к устаревшим ходам
  движка (например, при старте новой партии).
- **Меньше лагов на высоких сложностях:** поиск хода ограничен по времени, игра
  остаётся отзывчивой.
- **Премувы:** можно заранее задать ход во время хода соперника (красная
  подсветка), с возможностью отмены.

### Обновлённый интерфейс
- Обновлён визуальный стиль приложения: карточки, навигация, акценты, градиенты
  и общая компоновка.
- Добавлены новые темы оформления: **«Аврора»** и **«Янтарь»**.
- Переработанная главная страница с герой-блоком состояния системы и быстрыми
  действиями.

### Новые возможности
- **«Фокус» (Pomodoro):** таймер концентрации с пресетами работы/отдыха, паузой,
  прогрессом и уведомлением по завершении этапа.
- **Быстрая очистка (безопасно)** прямо на главной — освобождение места в один клик.
- Сохранены возможности 1.3.x: оценка здоровья системы, экспорт HTML-отчёта,
  автообновление AppImage из коробки, кроссплатформенность.

## Установка

| Платформа | Файл | Запуск |
|-----------|------|--------|
| Linux (любой) | `SkayClearTux-1.4.0-x86_64.AppImage` | `chmod +x` и запустить |
| Debian/Ubuntu | `SkayClearTux-1.4.0-amd64.deb` | `sudo apt install ./SkayClearTux-1.4.0-amd64.deb` |
| Fedora/RHEL/openSUSE | `SkayClearTux-1.4.0-x86_64.rpm` | `sudo dnf install ./SkayClearTux-1.4.0-x86_64.rpm` |
| Windows | `SkayClearTux-windows.zip` | распаковать, запустить `SkayClearTux.exe` |
| macOS | `SkayClearTux.dmg` | открыть образ, перетащить в «Программы» |

> **macOS (первый запуск).** Приложение не подписано — щёлкните правой кнопкой →
> **Открыть** → **Открыть**.

Из исходников:

```bash
git clone https://github.com/skayinray/SkayClearTux.git
cd SkayClearTux
python -m venv .venv
.venv/bin/pip install PySide6
.venv/bin/python SkayClearTux.py
```
