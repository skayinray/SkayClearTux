# SkayClearTux 1.2.0 — кроссплатформенный релиз

Первый по-настоящему кроссплатформенный выпуск: теперь SkayClearTux — это
**приложение только для ПК** (Linux, macOS и Windows) на единой кодовой базе.
Системные разделы работают через родные средства каждой ОС, а недоступные
функции аккуратно сообщают об этом и не роняют программу.

---

## Главное

### Кроссплатформенное ядро

Весь системный код переехал в слой `skaycleartux/backends/`:

- `base.py` — общий интерфейс и безопасные заглушки;
- `linux.py` — pacman/systemd/`/proc`/lm-sensors;
- `macos.py` — Homebrew/`launchctl`/`diskutil`/`pmset`/`log show`/`lsof`;
- `windows.py` — `winget`/`choco`/службы Windows/WMI/`ipconfig`/`netstat`/Журнал событий.

Бэкенд выбирается автоматически при запуске.

### Что теперь работает на каждой ОС

| Раздел | Linux | macOS | Windows |
|--------|:-----:|:-----:|:-------:|
| Очистка (категории мусора) | pacman/systemd/Flatpak/Docker | Homebrew/кэши/Xcode | `%TEMP%`/кэши/корзина |
| Процессы, службы, автозапуск | да | `launchctl` | службы Windows |
| Пакеты и обновления | `pacman` | `brew` | `winget`/`choco` |
| Сеть и порты | `ip`/`ss` | `ifconfig`/`lsof` | `ipconfig`/`netstat` |
| Датчики, батарея, железо | `lm-sensors` | `powermetrics`/`ioreg` | WMI |
| Журнал, диагностика | `journalctl` | `log show` | Журнал событий |
| Модули и твики ядра | да | — | — |

## Новые возможности

- **Палитра команд** — `Ctrl+K` (и `Ctrl+F`): быстрый переход к любому разделу
  и запуск действий простым поиском.
- **Системный трей** — значок с меню быстрых переходов, проверкой обновлений и
  выходом. По желанию окно сворачивается в трей при закрытии (с одноразовой
  подсказкой).
- **Горячие клавиши** — `F1` справка, `Ctrl+R` обновить страницу, `Ctrl+H`
  главная, `Ctrl+Tab` следующий раздел, `Ctrl+,` настройки, `Ctrl+Q` выход.
- **Дашборд** — новые метрики «Температура ЦП» и «Батарея».
- **Настройки** — новые разделы: трей и горячие клавиши.

## Изменения

- Версия — **1.2.0**.
- `system_tools.py` стал тонким фасадом над бэкендами (имена API сохранены,
  страницы не пришлось переписывать).
- `cleaner.py` переписан: категории мусора зависят от ОС.
- Все подписи, справка и подсказки приведены к кроссплатформенным формулировкам.
- Скрипты сборки и CI переехали в стандартные места
  (`.github/workflows/`, `packaging/`).

## Исправления

- Убран личный жёстко прописанный путь корзины (`/mnt/.../.Trash-1000`).
- Убраны иконки-эмодзи из списка категорий очистки.
- Устранены символы, которые Qt рисовал пустыми квадратами (эмодзи и редкие
  стрелки/геометрические знаки).
- Освобождение места на диске считается кроссплатформенно (`shutil.disk_usage`).

## Удалено

- Мобильные порты (Android APK, iOS/TestFlight, PWA-клиент). Проект теперь
  только для ПК.

## Установка

| Платформа | Файл | Запуск |
|-----------|------|--------|
| Linux | `SkayClearTux-1.2.0-x86_64.AppImage` | `chmod +x` и запустить |
| Windows | `SkayClearTux-windows.zip` | распаковать, запустить `SkayClearTux.exe` |
| macOS | `SkayClearTux.dmg` | открыть образ, перетащить в «Программы» |

> **Первый запуск на macOS.** Приложение не подписано — щёлкните по нему правой
> кнопкой → **Открыть** → **Открыть**.

Из исходников:

```bash
git clone https://github.com/skayinray/SkayClearTux.git
cd SkayClearTux
python -m venv .venv
.venv/bin/pip install PySide6
.venv/bin/python SkayClearTux.py
```
