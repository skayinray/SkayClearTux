# Поддержка

Нужна помощь с **SkayClearTux**? Вот куда можно обратиться.

## Документация

- [README.md](README.md) — установка, возможности, сборка, скриншоты.
- [docs/architecture.md](docs/architecture.md) — устройство проекта и как добавить экран или бэкенд.
- [docs/backends.md](docs/backends.md) — контракт бэкендов и примеры для Linux/macOS/Windows.
- [CONTRIBUTING.md](CONTRIBUTING.md) — как сообщить об ошибке и прислать изменения.
- Раздел **«Настройка → Справка»** внутри программы — каталог всех функций.

## Вопросы и обсуждения

- [GitHub Discussions](https://github.com/skayinray/SkayClearTux/discussions) —
  вопросы, идеи, показ настроек, обмен опытом.

## Ошибки и предложения

- [Сообщить об ошибке](https://github.com/skayinray/SkayClearTux/issues/new?template=bug_report.yml)
- [Предложить функцию](https://github.com/skayinray/SkayClearTux/issues/new?template=feature_request.yml)

Перед отправкой приложите версию программы, ОС и шаги воспроизведения — так
помощь придёт быстрее.

## Безопасность

Об уязвимостях не сообщайте в публичных Issues — см. [SECURITY.md](SECURITY.md).

## Где лежат логи

Если приложение работает нештатно, приложите файл лога:

| ОС | Путь |
|----|------|
| Linux | `~/.local/state/SkayClearTux/skaycleartux.log` (или `$XDG_STATE_HOME`) |
| macOS | `~/Library/Logs/SkayClearTux/skaycleartux.log` |
| Windows | `%LOCALAPPDATA%\SkayClearTux\Logs\skaycleartux.log` |

## Проект поддерживают

SkayClearTux развивается сообществом. Спасибо всем, кто сообщает об ошибках,
предлагает идеи и присылает Pull Request'ы.
